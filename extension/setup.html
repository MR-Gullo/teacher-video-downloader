LessonShelf Mac setup

This guide is for the LessonShelf 0.3.0 preview. A teacher-friendly Mac installer is not available for this preview.

If your school has already installed the companion, return to LessonShelf, open Help & setup, and choose Check connection.

Manual setup for school IT

The companion needs Python, yt-dlp and FFmpeg. Install them with Homebrew, then use the reviewed preview source:

  1. In Terminal, run brew install python yt-dlp ffmpeg.
  2. Download and unpack the matching preview source. Review the source and open its folder in Terminal.
  3. Run python3 scripts/install-macos.py --firefox.
  4. Reopen LessonShelf, expand Help & setup, and choose Check connection, then Check local tools.

The installer stops if it finds an existing companion or Firefox registration. Preserve existing downloads and active jobs before changing a setup. Protected media is not supported.
