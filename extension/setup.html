LessonShelf Mac setup

The normal Mac companion download is pending Developer ID signing and notarization.

Open the LessonShelf installation page

If your companion is already installed, return to LessonShelf, open Help & setup, and choose Check connection.

Already installed

Choose Check local tools to confirm yt-dlp, FFmpeg, FFprobe, N_m3u8DL-RE and Deno. The companion checks which engine can handle each video.

Installation preserves existing downloads and your queue. If an update reports a download is active, let it finish before updating.

Save only videos you have permission to use. Protected media is not supported.
