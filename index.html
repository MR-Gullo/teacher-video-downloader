Windows and Mac tester preview

Get LessonShelf ready

Choose your browser below for setup steps.

This is a local preview. There is no signed store release yet. Chrome uses developer mode; Zen / Firefox uses a temporary add-on that must be loaded again after the browser restarts.

This preview needs Chrome, Zen, or Firefox on a Windows or Mac computer. Extension installation is not supported on this phone or tablet.

Set up in Chrome

Download for Chrome
  1. Unzip the preview and keep the folder in a stable location.
  2. Open chrome://extensions, turn on Developer mode, and choose Load unpacked.
  3. Select the build/chrome folder. Press Option+Shift+V on Mac or Alt+Shift+V on Windows to open LessonShelf on the video page. On Mac, the optional local queue and conversion setup is in Mac setup.

Set up in Zen or Firefox

Download for Zen / Firefox
  1. Unzip the preview and keep the folder in a stable location.
  2. Open about:debugging#/runtime/this-firefox and choose Load Temporary Add-on.
  3. Select build/firefox/manifest.json. Press Option+Shift+V on Mac or Alt+Shift+V on Windows to open LessonShelf on the video page. On Mac, the optional local queue and conversion setup is in Mac setup.

After setup, try the sample video to check a direct download. Permanent distribution needs browser-store approval or signing. This preview does not install itself. If the shortcut is already in use, change it in your browser’s extension shortcut settings.

Optional Mac companion for page downloads and conversion

The companion needs Python 3, yt-dlp and FFmpeg installed. It runs locally and keeps its queue on your Mac. Windows can use direct file downloads in the browser without it.

  1. In Terminal, open the unzipped LessonShelf folder. If you use Homebrew, install the tools with brew install python yt-dlp ffmpeg.
  2. For Chrome, copy the extension ID shown on chrome://extensions and run python3 scripts/install-macos.py --chrome-id YOUR_32_LETTER_ID. Replace the placeholder with the ID.
  3. For Zen / Firefox, run python3 scripts/install-macos.py --firefox. To set up both together, add both options to one command.
  4. Open LessonShelf and select Reconnect, then Check local tools. The companion setup guide has troubleshooting and removal steps.

Do not replace an existing companion or host manifest without checking it first. The installer stops if it finds one.

A few things to know

Save only videos you have permission to use. Sites can block downloads, and protected or DRM media is not supported. The extension does not export browser cookies. Browser downloads may send the normal cookies for the requested site. Direct file downloads use your browser on Windows and Mac. Page downloads, queue recovery, and conversion need the optional Mac companion and its tools; they are not available on Windows in this preview.
