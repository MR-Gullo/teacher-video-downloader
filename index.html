Open this page on a Windows or Mac computer.

1. Install the extension

Install in Firefox / Zen

Open this link in Firefox or Zen, then approve the browser's installation prompt. No Developer mode.

2. Install the companion

Download Windows companion

The companion includes the download tools. Open the downloaded installer and choose Install. Return to LessonShelf and choose Check connection.

The normal Mac installer is waiting for Developer ID signing and notarization. Existing preview users can choose Help & setup, then Check connection.

Setup help

Firefox will ask to send the video links you select to the companion on this computer. Allow this to use the queue and conversion. Direct video files can also use your browser's normal downloads.

Windows x64 is supported. Windows ARM64 and Chrome are outside this beta. If your school blocks the installer, contact Joel.
