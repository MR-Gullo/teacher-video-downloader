# Mac acceptance checklist / handoff to a local agent

**Scope:** test this exact source package on the user's Mac after the user authorizes installation. Do not inherit VM success as browser/live-site success. No automatic bulk downloads, cookies, remote ASR or DRM bypass. Ask before new installs/external changes beyond the user's permission.

1. Verify ZIP SHA-256 from delivery, inspect source and run `python3 -m unittest discover -s tests -v` and `node tests/ui-unit.cjs`. Integration tests use a local HTTP server and a downloader stub. They are not real yt-dlp/N tests.
2. Follow MAC-SETUP. Confirm Python, yt-dlp, ffmpeg/ffprobe and optionally current N. Validate host allowlists against actual extension IDs. Confirm the browser **Check local tools** action returns. Firefox is temporarily loaded and must be reloaded after browser restart.
3. UI: inspect the popup, queue, settings and help. Check keyboard Tab/Space/Enter, screen-reader labels, theme persistence, multiple-player selection, private-window guard and stale navigation. Changing settings must never start downloads. Test missing native host and engine messages; restore afterward.
4. One short legal/public video with yt-dlp, first no copy, then classroom. Inspect resulting original, playable H264/yuv420p/AAC copy, source reference, chapters if available, and selectable English subtitle track. Confirm absent captions become warning, not fake success. Verify a title with Unicode and slash-like punctuation cannot escape output folder.
5. One direct clear HLS/DASH stream with N. Confirm actual CLI capabilities match installed version, no hidden interactive prompts, and source/copy outputs. Do not supply or extract decryption keys. If encrypted/DRM or inaccessible, stop and report.
6. On a user-authorized Knowledge page, start playback and use the current-video action. Confirm that the selected player matches the saved result. Cookie transfer is unavailable; a signed URL may expire or lack access. Do not scrape browser profiles to make it work.
7. Bad network: pause halfway, inspect `.part`/fragment files; Resume and confirm bytes are reused where engine/server supports it. Disable/re-enable network briefly only with user permission. For N record whether segments restart; do not label mere successful retry as resume. Try expired signed URL and confirm understandable failure, no bypass.
8. Close popup, close/reopen browser, relaunch worker and test sleep/wake. Explicitly test worker SIGTERM and SIGKILL while downloading; ensure no concurrent same-job engine, partials safe, interrupted status paused. Test real third-party descriptor inheritance (only cooperative stub inheritance tested in VM).
9. Repeated Download clicks/reconnect and changing page titles should not duplicate URL+settings. Pause/cancel at download completion and during encode must not be overwritten by Complete. Cancel keeps original/partial files by design.
10. AV1 on an expendable representative source: confirm skip low-res/already-efficient; inspect quality; validate retained copy only if>=15% smaller; original untouched. Test dry-run/no-compress CLI and existing-target collision protection.
11. Re-run aggregate tests after any fix; update report with exact binaries/versions and actual vs stub coverage. Do not mark production-ready until native-browser and real-engine gates pass. Keep a small source-only updated ZIP, never include cookies, signed URLs, queue DB, user downloads or raw engine logs.

**Required before claiming complete wrapper parity:** explicitly scoped authenticated-session design plus browser tests; actual Spokenly interface/privacy review and opt-in adapter. Neither feature exists in this preview. Broad `--cookies-from-browser` would read a profile locally and must not be misrepresented as origin-scoped.
